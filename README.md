# 이즈나 데스크톱 비서 · v0.4

Windows 10/11 Intel/AMD 64비트용 비공식 개인 팬 프로젝트입니다.
이즈나 이미지 45개, 이즈나·코코나 모드, 여러 채팅 탭과 장기 기억, 서비스별 AI 대화, 바탕화면 산책과 클릭 탄성 효과를 포함합니다. 코코나 이미지는 직접 추가해야 합니다.

## v0.4: 화면 조절과 주식 포트폴리오

- 장기 기억 요약을 짧은 **영어**로 생성합니다. 캐릭터의 일반 답변은 기존처럼 한국어로 생성합니다.
- 설정에 **화면** 탭을 추가했습니다. 캐릭터 높이 160–400px, 대화창 크기 75–150%, 캐릭터 투명도 25–100%, 대화창·주식창 투명도 35–100%를 조절할 수 있습니다.
- 캐릭터와 대화창·주식창의 **항상 위에 표시**를 각각 끄거나 켤 수 있습니다.
- 대화창의 **주식 · 포트폴리오**에서 미국·KRX·KOSDAQ 종목, 수량, 평균 매입가를 등록합니다. 현재가, 일간 등락률, 평가액, 손익과 수익률을 30초마다 갱신합니다.
- 이 기능은 조회와 수기 포트폴리오만 제공하며 주문하거나 증권계좌 잔고를 읽지 않습니다. 원화와 달러 평가액은 환율로 합치지 않고 별도로 보여줍니다.

### 주식 시세의 중요한 제한

기본 시세는 Yahoo Finance 공개 차트 데이터를 이용한 **비공식 연결**입니다. API 키 없이 시작할 수 있지만 거래소와 종목에 따라 지연될 수 있고, 공급사의 응답 제한·형식 변경으로 일시 중단될 수 있습니다. 화면의 “앱 수신 시각”은 앱이 응답을 받은 시각이지 거래소 체결 시각을 보장하지 않습니다. 투자 판단이나 주문 체결 기준으로 사용하지 마세요.

- 미국: `AAPL`, `NVDA`, `TQQQ`처럼 티커를 입력합니다.
- KRX: 시장에서 `국내 KRX`를 고르고 `005930`처럼 6자리 코드를 입력합니다.
- KOSDAQ: 시장에서 `국내 KOSDAQ`을 고르고 `247540`처럼 6자리 코드를 입력합니다.
- 수량 0과 평단 0도 허용하므로 관심종목처럼 등록할 수 있습니다.
- 포트폴리오는 `%LOCALAPPDATA%\\IzunaDesktop\\portfolio.json`에 평문으로 저장됩니다. 대화 기억 저장을 꺼도 포트폴리오는 유지됩니다.

진짜 체결 실시간 시세는 별도 공급사 계약과 인증이 필요합니다. 예를 들어 한국투자증권 공식 Open API는 계좌 연결, 서비스 신청, 앱키·앱시크릿 발급 및 웹소켓 인증을 요구합니다. 이 버전에는 해당 키 입력과 증권계좌 연동을 넣지 않았습니다.

## 바로 실행

1. `IzunaDesktop-Windows-Portable.zip`을 **전체 압축 해제**합니다.
2. `IzunaDesktop/RUN.bat`를 더블클릭합니다. Python 설치는 필요 없습니다.
3. 처음에는 정해진 대사를 보여주는 **데모 모드**로 시작합니다.
4. **설정 → API 서비스 선택 → API 키 입력 → 모델 선택/직접 입력 → 데모 모드 끄기 → 저장하기**.

기존 사용자는 이즈나를 우클릭해서 **종료**한 뒤 새 ZIP을 별도 폴더에 압축 해제하고 실행하세요. 기존 대화와 메모는 “이전 대화” 탭으로 자동 이전하며 서비스별 API 키와 모델 설정은 이어받습니다. v0.2에서 이미 삭제된 오래된 대화는 복구할 수 없습니다. 동시에 두 버전이 실행되지는 않습니다.

## v0.3: 캐릭터, 채팅 탭, 장기 기억

- **이즈나 모드 / 코코나 모드**: 대화창의 캐릭터 선택으로 전환합니다. 기본 지침에 각각 “블루 아카이브의 쿠다 이즈나”, “블루 아카이브의 스노하라 코코나”를 포함합니다. 설정의 성격·말투는 이 기본 지침에 추가됩니다.
- **캐릭터별 설정**: 호칭, 말투, 크기, 산책 속도를 별도로 저장합니다. 기본 호칭은 이즈나 “주군”, 코코나 “선생님”입니다. API 서비스와 모델, 산책 켜기/끄기와 클릭 효과는 공통 설정입니다.
- **여러 채팅 탭**: `새 대화`로 생성, 탭 클릭으로 선택, 더블클릭으로 이름 변경, 우클릭으로 이름 변경·복제·삭제합니다. 첫 메시지로 기본 제목이 붙습니다. 삭제 전 확인하며 마지막 탭 삭제 시 빈 탭을 만듭니다.
- **탭별 분리**: 원문 전체, 장기 기억 요약, 고정 메모, 입력 초안, 선택 캐릭터가 독립적입니다. 다른 탭의 대화를 자동으로 가져오지 않습니다. 복제한 탭은 복제 시점의 원문과 기억을 이어받고 이후에는 독립적입니다.
- **한 탭에서 캐릭터 전환**: 같은 대화를 이어갈 수 있습니다. 과거 답변의 캐릭터 이름을 보존하며 다른 캐릭터의 발언은 API에도 발언자를 표시합니다.
- **이전 대화 보기**: 처음에는 최근 60개를 표시합니다. 버튼을 누르면 이전 기록을 60개씩 더 볼 수 있습니다. 원문은 200개 제한 없이 보관합니다.
- 답변 또는 요약을 받는 동안에는 탭 생성·선택과 캐릭터 전환을 잠급니다. `중지` 후 바꿀 수 있습니다.

## 코코나 이미지 넣기

1. 대화창에서 **코코나 모드**를 선택합니다.
2. **설정 → 캐릭터 → 캐릭터 이미지 폴더 열기**를 누릅니다.
3. 그 폴더에 아래 규칙대로 PNG 또는 WebP 파일을 넣습니다.
4. **이미지 다시 읽기**를 누릅니다. 앱을 재시작해도 됩니다.

코코나 폴더: `%LOCALAPPDATA%\IzunaDesktop\characters\kokona`

| 용도 | 파일명 예시 |
|---|---|
| 기본 모습 | `Kokona.cozy.webp` |
| 미소 | `Kokona.smiling.webp` |
| 생각 중 | `Kokona.thinking.webp` |
| 신남 | `Kokona.excited.webp` |
| 왼쪽 걷기 | `Kokona.walking to left.webp` |
| 오른쪽 걷기 | `Kokona.walking to right.webp` |
| 잠자기 | `Kokona.sleeping.webp` |

파일명 접두사는 `Kokona.`, 표정명은 이즈나 파일과 동일하게 쓰면 됩니다. `.png`도 지원합니다. 투명 배경의 전신 그림이 어울립니다. **45개를 전부 준비할 필요는 없습니다.** 없는 표정은 같은 캐릭터의 `cozy` → `smiling` → 다른 사용 가능한 표정 순으로 대체합니다. 코코나 이미지가 하나도 없으면 이미지 추가 안내판을 표시하며 대화는 사용할 수 있습니다.

이즈나 교체 이미지는 `%LOCALAPPDATA%\IzunaDesktop\characters\izuna`에 `Izuna.cozy.webp` 같은 이름으로 넣습니다. 사용자 폴더의 해당 표정이 번들보다 우선합니다. 새 앱 ZIP으로 교체해도 이 폴더의 이미지는 유지됩니다. 원본 첨부 이미지는 수정하지 않았습니다.

## 대화 기억의 동작

API가 자동으로 이전 요청을 기억한다고 가정하지 않습니다. 매번 **캐릭터 지침 + 탭 고정 메모 + 이전 대화 요약 + 요약 이후 원문 + 새 메시지**를 전달합니다. 사용자 발언뿐 아니라 이전 AI 답변도 포함합니다.

[RisuAI의 SupaMemory 설명](https://github.com/kwaroran/Risuai/wiki/SupaMemory)에 있는 자동 요약·재요약 방식을 참고했습니다. RisuAI의 전체 기능이나 벡터 검색을 이식한 것은 아닙니다.

- 요약되지 않은 기록이 **40개 또는 총 24,000자**를 넘으면 다음 답변 전에 오래된 부분을 영어로 요약합니다. 메시지 수는 사용자와 AI를 각각 1개로 셉니다. 일반 대화 프롬프트에는 계속 한국어로 답하라는 지침이 들어갑니다.
- 오래된 기록은 한 번에 약 24,000자씩 처리하고, 최근 기록 일부는 원문으로 남깁니다. 큰 이전 기록을 처음 처리할 때는 요약 요청이 여러 번 이어질 수 있습니다.
- 기존 요약과 추가 기록을 합쳐 새 요약을 만듭니다. 원문은 삭제하지 않으며, 성공한 요약만 반영합니다. 요약 실패 시 원문을 보존하고 작성한 메시지를 입력창에 돌려줍니다.
- **설정 → 기억**에서 탭의 메모와 요약을 확인·수정할 수 있습니다. 요약을 비우면 다음 대화에서 원문을 다시 요약합니다. 대화 삭제 옵션은 현재 탭의 원문과 요약만 지우며 고정 메모는 남깁니다.
- 요약도 현재 선택한 서비스와 모델로 요청하므로 **추가 API 사용료**가 생길 수 있습니다. 요약은 세부 내용을 누락하거나 잘못 정리할 수 있어 중요한 정보는 고정 메모에 적어 두세요.
- 문자 수는 토큰 수와 다릅니다. 작은 컨텍스트의 모델이나 Ollama 서버의 컨텍스트 설정에서는 긴 대화가 한도를 넘거나 잘릴 수 있습니다. 해당 모델/서버의 컨텍스트 설정을 늘리거나 더 넓은 컨텍스트 모델을 사용해야 합니다. 모든 모델에서 정확한 기억을 보장하지는 않습니다.
- 데모 모드는 정해진 대사만 표시하고 요약 API를 부르지 않습니다. 데모/API를 전환하면 새 탭을 만들고 이전 탭은 보관합니다. 기존 데모 탭을 직접 선택하면 그 기록으로 이어갈 수 있습니다.

## 서비스별 연결

| 서비스 | 필요한 것 | 연결 방식 |
|---|---|---|
| OpenAI | OpenAI API 키 | Responses API |
| Google Gemini | Google AI Studio의 Gemini API 키 | Gemini generateContent |
| Anthropic Claude | Anthropic API 키 | Messages API |
| Ollama | 실행 중인 Ollama 서버 + 내려받은 모델 | 기본 `http://localhost:11434`, 로컬은 키 불필요 |
| Vercel | **AI Gateway API 키** | Gateway의 OpenAI 호환 Chat Completions |

Vercel의 일반 계정 토큰이나 배포 토큰을 넣는 기능이 아닙니다. 모델 ID는 `anthropic/claude-sonnet-5`처럼 제공사/모델 형식입니다.

Ollama 예시: Ollama를 설치·실행한 뒤 터미널에서 `ollama pull qwen3:8b`로 모델을 받습니다. 설정에서 Ollama를 선택하고 **설치된 모델 가져오기**를 누릅니다. 모델 다운로드나 Ollama 자체 설치는 이 앱이 자동 수행하지 않습니다. 큰 모델은 PC 메모리가 충분해야 합니다. 원격 Ollama를 지정할 경우 대화가 해당 주소로 전송됩니다. 서버 주소에는 `/api/chat`을 붙이지 마세요. 인증이 필요한 서버에는 API 키를 선택적으로 넣을 수 있습니다.

클라우드 API 사용료는 각 서비스에서 별도 청구될 수 있습니다. API 키·사용 크레딧은 포함되지 않습니다. API 모드 배지는 선택 모드 표시이며 연결 성공을 미리 보장하지 않습니다.

## 조작

| 조작 | 동작 |

| 캐릭터 왼쪽 클릭 | 탄성 효과 + 대화창 열기/닫기 |

대화창이 열려 있거나 마우스를 올리면 산책을 멈춥니다. 제공된 정지 그림에 상하 움직임을 더하며, Live2D나 관절 애니메이션은 아닙니다. 이미지의 투명 부분은 뒤쪽 창을 클릭할 수 있도록 알파 마스크를 사용합니다.

## 키와 저장

- 대화에 필요한 원문, 요약, 호칭·말투·탭 메모를 **선택한 서비스**로 보냅니다. 서비스나 모델을 바꾸어도 선택한 탭의 기억을 이어서 전달합니다.
- 캐릭터 이미지나 PC 화면, 파일을 API에 보내지 않습니다. 실제 PC 제어, 웹 검색, 일정 예약 기능은 없습니다.
- 키는 기본적으로 현재 실행에서만 사용합니다. 암호화 저장을 선택하면 Windows 사용자 계정의 DPAPI로 서비스별 파일에 저장합니다. 다른 서비스의 키를 섞어 사용하지 않습니다.
- 설정에서 서비스를 오가며 입력해도 초안이 남습니다. 저장하기를 누르면 편집한 서비스 설정을 저장하고 취소하면 적용하지 않습니다.
- “모든 채팅 탭과 기억 유지”를 켜면 탭의 원문, 요약, 메모, 초안을 PC에 평문 저장합니다. 끄면 디스크 대화 파일을 삭제하고 현재 실행 중에만 보관합니다. 캐릭터/연결 설정과 이전 버전에서 옮겨온 원래 설정 메모는 별도로 남습니다.
- 저장 경로: `%LOCALAPPDATA%\IzunaDesktop`. `settings.json`은 설정/캐릭터 프로필, `chats.json`은 탭과 기억, `characters`는 사용자 이미지, `api-key*.dpapi`는 암호화 키입니다.
- `history.json`은 v0.3의 `chats.json` 저장 성공 후 제거합니다. 구버전으로 되돌리면 새 대화는 구버전에 표시되지 않습니다.
- 중지는 네트워크 요청을 취소하지만 이미 처리된 사용량은 서비스에서 청구할 수 있습니다. 이미 성공한 요약은 유지하고 진행 중이던 응답만 취소합니다.

## 검증과 현재 범위

자동 테스트 37개 중 **36개 통과**, Windows DPAPI 테스트 1개는 OS가 달라 건너뛰었습니다. 로컬 테스트 서버로 5종 AI 서비스의 요청·응답, 인증 헤더 분리, 취소, 시간 초과, 모델 목록 가져오기를 확인했습니다. 캐릭터·창 크기와 투명도 설정, 포트폴리오 저장, 종목 코드 변환, 시세 응답 파싱과 손익 계산도 검사했습니다. 실제 Windows, 실제 AI 키, 외부 시세 서버 연결은 이 환경에서 검증하지 못했습니다.

이 환경에서는 **실제 Windows 바탕화면 실행, DPAPI, 실제 API 키를 사용한 5종 실연결은 검증하지 못했습니다.** 대화 API는 클라우드 90초, Ollama는 모델 로딩을 고려해 180초까지 기다립니다. 연결 실패는 대화창에 표시하며 자동 유료 재시도는 하지 않습니다.

음성, 효과음, Live2D, 전체화면 자동 감지, 외부 작업 실행은 아직 없습니다.

## 문제 해결

- 실행이 안 되면 전체 ZIP을 압축 해제했는지 확인하고 `DEBUG.bat`를 실행하세요. 오류 기록은 `%LOCALAPPDATA%\IzunaDesktop\startup-error.log`입니다.
- 키 오류: 선택한 서비스의 키인지 확인하세요. Ollama 로컬 모드는 키를 비워 둡니다.
- 모델 오류: 프리셋을 바꾸거나 정확한 모델 ID를 입력하세요. Ollama는 설치된 모델 가져오기로 확인할 수 있습니다.
- Vercel 모델 목록이 비어 있거나 오래됐다면 새로고침하세요.
- 이즈나가 안 보이면 트레이 숨겨진 아이콘을 확인하세요. 우클릭 → 종료로 완전히 종료할 수 있습니다.

## 소스 수정

소스 ZIP에는 런타임이 없습니다. Python 3.12 64비트를 설치하고 `RUN.bat`를 실행하면 의존성을 설치합니다.

```bash
python -m pip install -r requirements.txt
python app.py
python -m unittest discover -s tests -v
```

`app.py`는 UI/움직임, `providers.py`는 서비스별 요청·응답/모델 프리셋, `core.py`는 키와 기억, `network.py`는 비동기 통신입니다. Windows에서 `BUILD_EXE.bat`로 EXE 폴더를 만들 수 있습니다. 휴대용 배포는 포함된 `runtime/pythonw.exe`로 실행하며, 이 환경에서 Windows용 PyInstaller 빌드를 수행한 것은 아닙니다.
