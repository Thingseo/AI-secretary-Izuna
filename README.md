# 이즈나 데스크톱 비서 · v0.8

Windows 10/11 x64용 개인 팬 프로젝트. 사용자 제공 Python 3.12 / PySide6 런타임을 포함합니다. ZIP 전체를 새 폴더에 풀고 RUN.bat을 실행하세요. Python 별도 설치는 필요하지 않습니다. 오류는 DEBUG.bat으로 확인하세요.

## 대화

창 가장자리·모서리로 크기를 조절하고 마지막 위치·크기를 복원합니다. 대화 목록에서 검색·선택하고 우클릭으로 이름 변경·복제·삭제합니다. 대화별 초안과 장기 기억을 유지합니다. 설정 또는 캐릭터 우클릭 메뉴에서 현재 캐릭터를 바꾸고 이미지·호칭을 지정합니다. 새 대화는 현재 캐릭터를 그대로 이어받으며, 이전 답변의 발언자 정보는 유지됩니다. 구버전 인터페이스 배율과 기본 캐릭터 설정값은 오류 없이 무시됩니다.

## 수동 자산

상단 선택 메뉴에서 보유종목·도넛·월별 성과·관심종목·매매 기록을 전환합니다. ‘+ 자산 추가’와 ‘선택 수정’은 별도 입력창을 엽니다. 기본 목록은 종목·현재가·수량·평가액만 표시하고 ‘손익 자세히’로 추가 열을 표시합니다. 도넛과 범례는 나란히 배치하며 화면 전환 후에도 목록 높이를 유지합니다.

증권사 API, 인증, 실제·모의계좌 가져오기 화면과 코드를 제거했습니다. 기존 사용자의 과거 파일은 자동 삭제하지 않으며 읽지 않습니다.

- 보유종목: 시장·코드·수량·평단·계좌·섹터를 입력합니다. 같은 계좌/시장/코드로 추가하면 수정됩니다. 현금은 체크 후 수량에 금액을 입력합니다. 국내 현금은 KRX를 선택하세요.
- 도넛: 종목·섹터·계좌·통화 분류, 현금 포함, 기타 묶음, 클릭 상세, 집중도 표시. USD/KRW 수동 환율과 표시 설정을 저장합니다. 평가 가능한 자산만 집계하며 가격·환율 누락과 오래된 시세를 경고합니다.
- 관심종목: 시장,종목코드,이름으로 등록합니다. 더블클릭 내부 차트, 우클릭 TradingView/Yahoo Finance를 지원합니다.
- 매매 기록: 날짜,시장,코드,계좌,매수/매도,수량,가격으로 입력합니다. **기록 전용**으로 보유수량·현금은 직접 수정해야 합니다. 같은 계좌의 보유종목 차트에 거래일 ▲매수/▼매도를 표시합니다. 표시는 일봉 고가 위이며 체결가격 좌표가 아닙니다.
- 월별 성과: 첫 줄에 연-월,월초 총자산,월말 총자산을 입력합니다. 다음 줄부터 날짜,입출금액을 입력합니다. 모든 금액은 직접 원화 환산하며 입금은 양수, 출금은 음수입니다. 매매대금은 외부 입출금에 포함하지 않습니다. 손익과 일말 입출금 기준 Modified Dietz 추정 수익률을 계산합니다. 투자자본이 0 이하이면 수익률은 계산 불가입니다. 과거 실적 자동 복원은 없습니다.

내부 차트는 캔들/라인, 거래량, MA 5·20·60·120, RSI, 기간, 줌·이동, SPY·QQQ·SOXX·KOSPI 비교를 제공합니다. 비교는 공통 날짜 가격을 재조정하며 배당·환율을 반영한 총수익률은 아닙니다. 누락·분할 안내를 확인하세요. Yahoo Finance 공개 데이터의 비공식 연결로 시세 지연과 조회 실패가 가능합니다. 주문 기능은 없습니다.

## MCP

### 채팅으로 실제 폴더 정리와 감상 저장

1. 설정에서 데모를 끄고 실제 AI API 또는 실행 중인 Ollama 모델을 연결하세요.
2. 대화창 ‘⋯ → 폴더 작업 시작…’에서 작업 폴더를 선택하세요. 파일 이름과 읽은 텍스트가 선택한 AI 서비스에 전송됨을 확인합니다.
3. ‘이 폴더를 종류별로 정리하고, 읽은 내용을 바탕으로 감상.txt를 저장해줘’라고 채팅하세요.
4. 앱이 번들 로컬 MCP 서버로 목록과 텍스트를 읽고 모델에 결과를 전달합니다. 최대 18단계 안에서 전체 변경 계획을 만듭니다.
5. 이동 전후 경로와 저장할 본문이 표시됩니다. ‘이 내용으로 실행’을 누르면 실제 이동과 저장을 실행합니다. 취소하면 파일을 변경하지 않습니다.
6. 완료 메시지와 실제 폴더를 확인하세요. 채팅 상단의 폴더 표시를 클릭하거나 ‘⋯ → 폴더 작업 종료’로 일반 대화로 돌아갑니다. 폴더 권한은 실행 세션에만 유지됩니다.

별도 MCP 설치나 JSON 입력이 필요하지 않습니다. 폴더 작업 모드에서는 이후 채팅도 선택한 폴더에 적용합니다. 읽기 단계에서 중지할 수 있으며 승인한 변경을 적용하는 동안에는 완료를 기다립니다.

지원 범위: 폴더당 최대 150개 항목, 이동 파일당 20MB 이하, 계획당 최대 50개 변경. 새 하위 폴더를 만들고 파일을 이동할 수 있습니다. 읽기는 64KB 이하 UTF-8 텍스트(txt/md/csv/json/log/py/html/css/xml/yaml/yml), 새 파일은 txt/md만 지원합니다. 사진·PDF·Office는 파일 이름을 기준으로 분류할 수 있으나 내용을 읽고 감상하지는 못합니다. 내용은 실제로 읽은 텍스트에 근거하도록 요청하며 최종 본문을 확인하세요.

선택 폴더 밖, 숨김 경로, 심볼릭 링크·정션·하드링크, 기존 파일 덮어쓰기, 파일 삭제, 프로그램 실행은 차단합니다. 목록 확인 뒤 바뀐 파일도 거절합니다. 이동은 같은 파일시스템의 하드링크 생성 후 원래 이름을 제거하여 원본 데이터를 유지합니다. 일반 실행 오류에는 수행한 작업을 되돌리지만 앱 강제 종료·전원 차단·동시 외부 수정까지 완전한 트랜잭션을 보장하지 않습니다. 적용 중에는 앱과 해당 파일을 종료·수정하지 마세요. 원격 모델 호출에는 추가 API 비용이 발생할 수 있습니다. 결과와 생성 본문은 사람이 확인해야 합니다.

폴더 작업의 완료 결과는 일반 대화 저장 정책을 따릅니다. 읽은 원문·중간 도구 결과는 작업 중 메모리에서 사용하며 별도 감사로그에 저장하지 않습니다.

설정 → 도구·MCP에서 HTTPS 또는 내장 stdio 테스트 서버를 등록하고 연결·도구 목록을 확인합니다. 도구별 허용과 읽기 분류를 저장하세요. 쓰기/미분류는 항상 실행 전 확인합니다. 임의 로컬 프로그램 등록은 지원하지 않습니다.

원격 MCP 관리창은 현재 모델로 단일 도구 선택 → 실행 확인 → 결과를 대화에 전달 → 최종 답변을 지원합니다. 위의 번들 폴더 작업은 여러 번의 읽기와 최종 변경 계획을 채팅에서 중계합니다. 취소는 이미 처리된 원격 작업을 되돌리지 않습니다.

실행 기록은 mcp-events.json에 최근 200건의 시간·서버 ID·상태만 저장합니다. 인자·결과·인증정보는 기록하지 않습니다. 관리창의 실행 기록 보기에서 확인합니다.

## 저장과 개인정보

업데이트 전에 앱을 종료하고 `%LOCALAPPDATA%\IzunaDesktop` 폴더를 백업하세요. 설정은 settings.json, 보유종목·관심종목·기록의 통합 원자적 저장 파일은 portfolio-state.json입니다. portfolio.json도 하위 호환용으로 저장합니다.

대화 저장을 켜면 원문·요약·초안을 평문으로 보관합니다. 선택한 AI 제공사에 대화와 기억을 전송합니다. MCP 결과는 사용자 확인 후 전달하므로 개인정보를 확인하세요. AI API 키와 MCP 토큰은 선택 시 Windows DPAPI로 암호화 저장하며 비Windows에서는 세션에서만 사용합니다. API 비용과 서버 이용 권한은 별도입니다.

## 검증 범위

Linux Qt offscreen 회귀 테스트를 사용했습니다. Windows 실제 실행·다중 모니터·DPI·DPAPI와 실제 외부 API 연결은 검증하지 못했습니다. GitHub 게시와 Windows EXE 빌드는 수행하지 않았습니다. 이 ZIP은 동봉 Windows Python으로 소스를 실행합니다.
